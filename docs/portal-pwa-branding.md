# Portal PWA branding

The Admin install uses `public/manifest.json` and the name Consolium. The existing Team Leader and Team Management installs keep `team-manifest.json` and `team-management-manifest.json` with their `installedPortal` start URLs and route protection. Once team context loads, `applyPortalPwaMetadata` selects a team-specific manifest. The Stage venue route selects a venue-specific manifest from its URL, then updates the name when venue context loads. The dynamic `/portal-manifest` endpoint returns a distinct app ID for that team or venue. Cloudflare Pages serves the route from `functions/portal-manifest.ts`; Vercel uses `api/portal-manifest.ts` and its explicit rewrite. Both derive asset and start URLs from the request origin, so changing the deployment domain requires no source edit.

All portal installs use the Consolium artwork in `public/brand`. The same crest is used for the Expo native app icons and portal headers. iOS touch icons include 152, 167, and 180 pixel variants; Android has 192, 512, and maskable 512 pixel PNGs. The existing Main and Team install prompts remain in use; `PwaInstallCard` serves the Stage venue page.

QR and copied browser links use the current origin. Native builds have no browser origin; set `EXPO_PUBLIC_APP_ORIGIN` to the public HTTPS app origin when building a native app to enable external QR links. This branding change does not modify tenant data, authorization, or database schema.
